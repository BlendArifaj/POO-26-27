## 📚 About This Repository

This repository contains practical materials, code examples, exercises, and assignments for the **Object-Oriented Programming (OOP)** course.

Its primary purpose is to help students develop a solid understanding of object-oriented programming principles through practical Java programming.

The repository will be updated throughout the semester with examples demonstrated during practical sessions, additional exercises, and supporting learning resources.

## 🎯 Learning Objectives

By the end of the course, students should be able to:

- Understand the fundamental principles of object-oriented programming.
- Define and use classes, objects, attributes, and methods.
- Understand constructors, static members, and access modifiers.
- Apply encapsulation, inheritance, polymorphism, and abstraction.
- Work with interfaces and abstract classes.
- Handle exceptions and common programming errors.
- Use Java collections and basic data structures.
- Design and implement object-oriented applications.
- Write readable, reusable, and maintainable Java code.

## 💻 Getting Started

### Prerequisites

Students should have the following installed:

- **Java Development Kit (JDK)** — Java 17 or newer recommended.
- **IDE** — IntelliJ IDEA, Eclipse, or Visual Studio Code with Java extensions.
- **Git** — To clone and manage the repository.

### Clone the Repository

```bash
git clone <repository-url>
cd <repository-directory>
```

### Running Java Examples

Navigate to the directory containing the example.

For a simple Java program:

```bash
javac Main.java
java Main
```

Alternatively, open the project in your preferred IDE and run the corresponding `main()` method.

Some examples may contain multiple Java files and should be compiled together or run through the IDE.

## 📝 Exercises and Assignments

Students are encouraged to solve exercises independently before reviewing the provided examples or solutions.

When completing exercises:

1. Read the requirements carefully.
2. Identify the necessary classes, attributes, and methods.
3. Implement the solution using Java.
4. Test the application with different inputs.
5. Consider edge cases and invalid inputs.
6. Keep the code clean and properly organized.

**Important:** The provided solutions and examples are intended for educational purposes. Understanding the implementation is more important than simply obtaining the correct output.
